SPSC RING BUFFER: MECHANICAL DESIGN

ATOMIC ACQUIRE-RELEASE ALIGNAS(64) POWER-OF-TWO MASK

The volt::SPSCQueueStatic is a fixed-capacity, single-producer single-consumer wait-free ring buffer. It achieves lock-free concurrent synchronization across two dedicated processor cores without operating system kernel mediation, mutexes, or atomic comparison-and-swap (CAS) loops.

HARDWARE FACT: 64B CACHE GRANULARITY & MESI

On x86-64 processors, memory is transported between caches and RAM in discrete 64-byte cache lines. When two distinct CPU cores read and write separate variables situated within the same 64-byte segment, hardware cache-coherency protocols (MESI / MOESI) enforce inter-core invalidation broadcasts. Writing to one variable invalidates the entire cache line in the other core, provoking false sharing and bus contention stalls.

MECHANICAL SOLUTION: ALIGNAS(64) ISOLATION

By applying alignas(64) (or alignas(std::hardware_destructive_interference_size)), the compiler forces the producer's write cursor (tail_) and consumer's write cursor (head_) into isolated 64-byte cache lines. Each core retains exclusive ownership of its active line in the Modified (M) or Exclusive (E) state, generating zero invalidation bus traffic.

PANEL STRIP 1 // CACHE LINE ISOLATION & FALSE SHARING EXACT BYTE-OFFSET VECTOR DIAGRAM
PANEL 1.A // UNPADDED STRUCT (64B CACHE LINE) COLLISION: MESI INVALIDATION

Both head_ (8B) and tail_ (8B) reside within identical 64-byte cache line 0x00 - 0x3F. Concurrent stores by Core 0 trigger continuous MESI invalidation ping-ponging on Core 1.

MICROARCHITECTURAL PENALTY: Core 0 store transitions line to Modified (M), transmitting an invalidation message over interconnect. Core 1 suffers an L1 D-Cache miss and pipeline stall.
PANEL 1.B // CACHE-ALIGNED STRUCT (128B SPLIT) ISOLATION: 0 INVALS

alignas(64) forces head_ and tail_ across a 64-byte boundary. 56 bytes of halftone-shaded padding isolate each cursor into its own cache line.

VERIFIED GUARANTEE: Core 0 writes exclusively to Cache Line 1 (0x40), while Core 1 reads exclusively from Cache Line 0 (0x00). False sharing is mathematically eliminated.
PANEL STRIP 2 // C++23 TRY_PUSH() & ASSEMBLY INSPECTOR
MECHANICAL IDENTITY & HARDWARE MAPPING
BITWISE WRAP-AROUND: (head + 1) & mask_ / (tail + 1) & mask_
When capacity $C$ is constrained to a power-of-two ($2^k$, verified by std::has_single_bit(Cap)), mathematical modulo $(x \pmod{2^k})$ is identical to bitwise AND $(x \ \& \ \text{mask\_})$ where $\text{mask\_} = \text{Capacity} - 1$. In x86-64 assembly, and reg, 1023 executes in 1 CPU cycle with 0.25 cycle reciprocal throughput, bypassing the non-pipelined integer division unit (idiv), which incurs 10 to 35 CPU cycles of latency and stalls execution port 0.

template <typename T, std::size_t Cap>
    requires (Cap > 0 && std::has_single_bit(Cap))
class SPSCQueueStatic {
public:
    static constexpr std::size_t Mask = Cap - 1;

    bool push(const T& value) {
        const auto tail = tail_.load(std::memory_order_relaxed);
        if (tail - cached_head_ == Cap) {
            cached_head_ = head_.load(std::memory_order_acquire);
            if (tail - cached_head_ == Cap)
                return false; // Buffer full
        }

        // Power-of-two bitwise modulo (1 cycle latency)
        std::construct_at(ptr(tail & Mask), value);

        // Release store publishes element to consumer
        tail_.store(tail + 1, std::memory_order_release);
        return true;
    }

    bool pop(T& out) {
        const auto head = head_.load(std::memory_order_relaxed);
        if (cached_tail_ == head) {
            cached_tail_ = tail_.load(std::memory_order_acquire);
            if (cached_tail_ == head)
                return false; // Buffer empty
        }
        T* element = ptr(head & Mask);
        out = std::move(*element);
        std::destroy_at(element);
        head_.store(head + 1, std::memory_order_release);
        return true;
    }
private:
    alignas(64) std::atomic<std::size_t> head_{0};
    alignas(64) std::atomic<std::size_t> tail_{0};
    alignas(64) std::size_t cached_head_{0};
    alignas(64) std::size_t cached_tail_{0};
};

LINEAR ARENA & FIXED-SLOT POOL ALLOCATORS

BUMP-POINTER O(1) INTRUSIVE FREELIST ZERO LOCKS

General-purpose dynamic memory allocators (such as malloc, free, or ptmalloc) maintain complex internal data structures: segregated size classes, free-list linked lists with pointer-chasing traversals, per-chunk boundary tags (metadata overhead of 8-16 bytes per allocation), and multithreaded lock contention or thread-cache synchronization.

LINEAR ARENA ALLOCATOR O(1) BUMP

MECHANICS: Memory is allocated sequentially along a pre-reserved contiguous span. Allocation is a single alignment addition and pointer bump. Deallocation is strictly $O(1)$ by resetting current_ = begin_ or rewinding to a saved Marker. Zero per-object metadata headers.

FIXED-SLOT POOL ALLOCATOR INTRUSIVE FREELIST

MECHANICS: Fixed-capacity slots of uniform size SlotSize = max(sizeof(T), sizeof(uint32_t)). Free slots embed the integer index of the next available slot directly inside the unused memory chunk. Zero external overhead; $O(1)$ pop and push onto the embedded singly-linked list.

#pragma once
#include <bit>
#include <cstddef>
#include <cstdint>
#include <cassert>

namespace volt {
    class LinearAllocator {
    public:
        using Marker = std::byte*;

        LinearAllocator(void* memory, std::size_t size) noexcept
            : begin_(static_cast<std::byte*>(memory)),
              current_(begin_),
              end_(begin_ ? begin_ + size : nullptr) {}

        void* allocate(std::size_t size, std::size_t alignment = alignof(std::max_align_t)) noexcept {
            assert(alignment > 0 && std::has_single_bit(alignment));

            const auto current = reinterpret_cast<std::uintptr_t>(current_);
            const auto aligned = (current + alignment - 1) & ~(alignment - 1);
            const auto end = reinterpret_cast<std::uintptr_t>(end_);

            if (aligned > end || size > end - aligned)
                return nullptr;

            current_ = reinterpret_cast<std::byte*>(aligned + size);
            return reinterpret_cast<void*>(aligned);
        }

        void reset() noexcept { current_ = begin_; }
        Marker mark() const noexcept { return current_; }
        void rewind(Marker marker) noexcept {
            assert(marker >= begin_ && marker <= current_);
            current_ = marker;
        }
    private:
        std::byte* begin_{nullptr};
        std::byte* current_{nullptr};
        std::byte* end_{nullptr};
    };
}
volt/memory/PoolAllocator.hpp COMPILABLE C++23 
#pragma once
#include <algorithm>
#include <cassert>
#include <cstdint>
#include <memory>

namespace volt {
    template <typename T, std::size_t Capacity>
    class PoolAllocator {
        using Index = std::uint32_t;
        static constexpr Index InvalidIndex = ~Index{0};
        static constexpr std::size_t SlotSize = std::max(sizeof(T), sizeof(Index));
        static constexpr std::size_t SlotAlign = std::max(alignof(T), alignof(Index));
    public:
        PoolAllocator() noexcept {
            for (Index i = 0; i < Capacity - 1; ++i)
                *reinterpret_cast<Index*>(slot_ptr(i)) = i + 1;
            *reinterpret_cast<Index*>(slot_ptr(Capacity - 1)) = InvalidIndex;
        }

        T* allocate() noexcept {
            if (free_head_ == InvalidIndex) return nullptr;
            Index idx = free_head_;
            free_head_ = *reinterpret_cast<const Index*>(slot_ptr(idx));
            ++size_;
            return reinterpret_cast<T*>(slot_ptr(idx));
        }

        void deallocate(T* ptr) noexcept {
            assert(ptr != nullptr);
            Index idx = slot_index(ptr);
            *reinterpret_cast<Index*>(slot_ptr(idx)) = free_head_;
            free_head_ = idx;
            --size_;
        }
    private:
        alignas(SlotAlign) std::byte storage_[Capacity * SlotSize];
        Index free_head_{0};
        std::size_t size_{0};
        std::byte* slot_ptr(Index idx) noexcept { return storage_ + idx * SlotSize; }
        Index slot_index(const T* ptr) const noexcept {
            return static_cast<Index>((reinterpret_cast<const std::byte*>(ptr) - storage_) / SlotSize);
        }
    };
}

CACHE-CONSCIOUS CONTAINERS: SPATIAL LOCALITY

FASTRingBuffer SMALLVECTOR SBO STREAM PREFETCHING

CPU hardware stream prefetchers observe contiguous memory access patterns. Traversing node-based pointer containers (such as std::list or std::map) causes recurrent cache line misses due to heap address scattering. Volt structures enforce spatial proximity.

FASTRingBuffer: BRANCHLESS ZERO-DIVISION

In volt::FastRingBuffer<T, Cap>, push and pop operations calculate target slot addresses using index & (Cap - 1). Because capacities are static powers of two, the modulo arithmetic compiles to a single and instruction. Sequence counters increment monotonically on 64-bit integers, requiring zero conditional reset branches.

SmallVector: SMALL BUFFER OPTIMIZATION (SBO)

volt::SmallVector<T, N> embeds an inline array of $N$ contiguous elements directly into the struct's own footprint. Small collections (e.g. per-entity component lists, job dependencies) avoid heap allocations entirely, ensuring cache lines loaded for the container metadata immediately contain the payload data.

volt/Containers/FastRingBuffer.hpp BRANCHLESS C++23 
template <typename T, std::size_t Cap>
    requires (Cap > 0 && std::has_single_bit(Cap))
class FastRingBuffer {
public:
    static constexpr std::size_t Mask = Cap - 1;

    bool push(const T& value) {
        if (full()) return false;
        std::construct_at(ptr(tail_ & Mask), value);
        ++tail_;
        return true;
    }

    void pop() {
        assert(!empty());
        std::destroy_at(ptr(head_ & Mask));
        ++head_;
    }

    [[nodiscard]] constexpr bool full() const noexcept { return (tail_ - head_) == Cap; }
    [[nodiscard]] constexpr bool empty() const noexcept { return head_ == tail_; }
private:
    alignas(alignof(T)) std::byte storage_[Cap * sizeof(T)];
    std::size_t head_{0};
    std::size_t tail_{0};
    T* ptr(std::size_t index) noexcept { return reinterpret_cast<T*>(storage_ + index * sizeof(T)); }
};
